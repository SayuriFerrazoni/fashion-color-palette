# Fashion Color Palette Generator

## Overview

This Python project generates color palettes based on styles, seasons, and different times of day.

The palettes generated are formed by colors associated with each style available in the program. The styles available are Elegant, Romantic, Minimalist, Spring, Summer, Autumn, Winter, Dawn, Day, and Night.

The objective of this project is to provide useful information for styling based on colors known from each style so that users are able to combine colors that fit their aesthetic.

## Features

- **Palettes:** Different color combinations for inspiration and to create harmonious and fashionable outfits.
- **Season styles:** Spring, Summer, Autumn, and Winter.
- **Time of the day styles:** Dawn, Day, and Night.
- **HEX color codes:** The user is able to view the color codes for each shade.

## Built With

- Python
- Matplotlib

## How to Run the Project

### Prerequisites

- Python 3
- pip

### Download and Installation

1. Download the repository

2. Install Matplotlib:

   ```bash
   python3 -m pip install matplotlib
   ```
3. Run the program:

```bash
python3 fashion_palette.py
```

The program will prompt the user to select one of the available styles. After selecting a valid style, the program displays the selected color palette and saves it as a PNG image.
